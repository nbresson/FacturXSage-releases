# FacturXSage — versions publiées

Ce dépôt contient uniquement les versions publiées de **FacturXSage**, l'outil qui affiche et rattache
dans Sage 100 Comptabilité le PDF d'origine embarqué dans les factures électroniques (UBL / CII / Factur-X).

Le code source n'est pas public.

## Télécharger

Les installeurs (`FacturXSage-<version>.msi`) sont dans les [releases](../../releases).
L'installation se fait en administrateur, pour toute la machine.

L'application consulte ce dépôt pour savoir si une nouvelle version est disponible.
